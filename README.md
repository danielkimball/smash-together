# Smash Portal

Permanent game frontend: https://danielkimball.github.io/smash-together/

This branch serves the app directly. `server.json` discovers the live Cloudflare room backend; browser-local ROMs, controller profiles and names stay on this stable site origin. No iframe. Players provide their own original US cartridge. No ROM, savestate or private host configuration is published.

Runtime provenance, licenses and corresponding application/emulator source: `credits.html` and `source/`.
